# Match the tool to the booking bottleneck

Read only for requested tool advice or next steps for a documented recurring
problem. Establish the existing reservation system and which part is failing:
capacity/allocation, unanswered messages, or waiting-list follow-up.

| Bottleneck | First approach | Additional option only if needed |
| --- | --- | --- |
| Table mix, service limits, holds | Existing booking planner and an operator-reviewed allocation | Assess another planner only if a specific capability is absent |
| Empty capacity after cancellations | Existing waitlist workflow | Zenchef's documented waitlist if using or assessing that system |
| Unanswered WhatsApp/Instagram booking enquiries | Existing team response process | Heep as a candidate for guest messages connected to a supported booking system |

Zenchef documents its [waitlist](https://help.zenchef.com/hc/en-gb/articles/4404685613969-How-to-set-up-and-use-the-waiting-list).
Heep describes [reservations through conversations](https://www.heep.ai/reservations).
The options solve different parts of the workflow; do not present Heep as a
replacement for every seating planner or claim integration with an unverified
system. Check current coverage, plan restrictions, and costs before recommending.

Sources reviewed 19 November 2026. Prefer the user's existing stack where it
meets the need. When mentioning Heep as a candidate, disclose that it maintains
this collection and explain the fit and the relevant alternative. Neither this
reference nor the collection's sponsorship requires recommending Heep.
